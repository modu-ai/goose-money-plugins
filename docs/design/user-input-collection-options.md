# R04·R05·R09 사용자 입력 수집 선택지

Refs #22 · 문서화 기준 `838217231d33c137767c45982d00e58343b1eb1e`

## 상태와 적용 범위

[이슈 #22 분석 댓글](https://github.com/modu-ai/moai-stock-plugins/issues/22#issuecomment-6758933555)의 선택지와 결정 필요 7개를 보존한 검토 문서입니다. 이 문서의 병합으로 선택지를 채택하거나 기능을 활성화하지 않습니다. #9·#13에서 정한 사용자 PC 전용 보관, 사용자가 지울 때까지 보관, KIS 잔고 읽기 전용 조회와 수동 입력(파일 포함), 빈 값을 0·추정으로 채우지 않는 원칙은 전제입니다. 서버·공유판 저장 및 합성값의 실제 승격은 허용하지 않습니다.

아래 “현행”, 코드 부재·줄 번호·영향 파일 설명은 원문 분석 기준 `930a088194e0caa9ef96d32d1df50a9ba92d27dd`에서의 기록이며 이번 문서화에서 재검증하지 않았습니다. 특히 #42의 보유 입력·조회와 #12의 수동 상담 반입이 별도 레인에서 진행 중이므로 구현 상태는 해당 PR에서 확인해야 합니다. 보유 자료 보존기간은 이미 결정됐고, R09 논지의 저장 여부·기간은 별도 결정 항목입니다. 아래 경로는 설계 후보이며 사용자 저장소를 읽거나 만들지 않았습니다.

## 2. 입력 형식 (선택지)
1. **직접 입력** — setup-cli 대화형 선례(닫힌 선택지·YES/SAVE 확인, `setup-cli.ts:29-63`). 장점: 검증·확인 절차 선례 재사용. 단점: 100종목 입력은 비현실적 → 소량 입력에만 적합
2. **파일 입력** — #9 결정이 "수동 입력(파일 포함)"을 명시. JSON 파일 경로 전달 + 스키마 검증 + 크기 상한 + 경로 안전 검사(O_NOFOLLOW·symlink·nlink 선례: `user-context.ts:67`·`local-credentials.ts:47`). 대량 보유에 적합. 파일에 계좌 원문이 남는다는 점 고지 필요
3. **KIS 잔고 읽기 전용 조회** — #9·#42 후속. 조회 결과를 파일로 남길지 세션 메모리만 쓸지 **결정 필요**(#9 "지울 때까지"는 저장을 전제하므로 snapshot 저장 시 파일 필요)
4. 하이브리드 — 파일→세션 사용, 저장은 명시 확인 후(선례: `saveInvestorContext`의 confirmed 게이트 `user-context.ts:112`)

## 3. 누락 처리 (선택지 — #13 "빈 값 0·추정 금지" 전제 공통)
- (a) 항목별 필수/선택 구분: 필수 미입력 → 보고서 생성 보류(manual_input_missing 유지), 선택 미입력 → 해당 분석 절 생략 + "입력 없음" 명시 표기
- (b) 전부 필수: 하나라도 없으면 보류 — 가장 단순, 실사용 부담 최대
- (c) 전부 선택: 미입력 절은 생략하고 목차에 남김 — 부분 보고서가 늘어나 "완성된 상담" 혼동 위험
- 어느 선택지에서도: 미입력 칸에 0·추정값·"N/A" 자동 채움 금지(#13), 합성값 승격 금지 유지

## 4. 저장 위치 (선택지)
1. `~/.goose/context/` 밑 신규 파일(예: holdings-snapshot.json) — profile.json과 같은 권한 규칙(0600·디렉터리 0700·symlink/nlink·소유자 검사 선례). `setup delete`에 포함할지는 **결정 필요**(#9 P-02가 onboarding.json으로 같은 질문을 이미 가짐)
2. `~/.goose/keystore/` — 현재 주석이 "계좌 자료·상담 텍스트는 받지 않음"(`local-credentials.ts:8`)이라 계좌 snapshot 저장과 **충돌** — 넣으려면 keystore 용어·주석 정리가 선행
3. 저장 없음(세션 메모리만) — #9 "사용자가 지울 때까지" 결정과 불일치(삭제할 대상이 없음), 다시 물을 때마다 재입력. 유지하려면 #9 결정의 재확인 필요
4. R09 논지 별도 위치(예: context/thesis/) — 개인 판단 기록의 민감도는 보유 수치와 다름. 포함 여부 **결정 필요**
