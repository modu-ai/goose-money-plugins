# 개인 보유 자료 입력과 로컬 보관 (#42)

## 구현 범위

`server/src/user-holdings.ts`는 직접 입력과 JSON 파일 입력을 검증하고, 명시적으로 확인된 snapshot을 사용자 PC에 보관한다. `createHoldingsService`는 호스트가 주입한 **F14 권한 판정**이 `allow/paid`일 때만 수집·조회·저장한다. 신원·구독 정보를 보유 자료와 함께 보내지 않는다. 미설정·무료·거부·판정 오류는 모두 거부한다. #7 평가기를 연결하는 지점은 이 생성자의 `authorize` 콜백이다. 권한 결과를 모델이나 도구 인자로 받으면 안 된다.

현재는 로컬 서비스 API와 합성 시험 단계다. 로그인 호스트 연결, 대화형 입력 화면, 파일 가져오기 CLI, MCP 계좌 도구 및 보고서 자동 입력은 아직 연결하지 않았다. `manual(value)`는 직접 구조화 입력, `fromFile(path)`는 명시한 파일만 읽는다. 파일 경로·계좌 식별자를 모델 입력으로 수집하지 않는다.

## 수동 입력 계약

필수는 `as_of`(유효한 달력 날짜), `currency`(대문자 3자리 통화 코드), `positions` 배열이다. 각 종목은 `symbol`을 갖는다. `quantity`, `market_value`, `cost_basis`, 계좌 전체 `cash`·`liabilities`는 선택 필드다. 수치는 음수가 아닌 십진 **문자열**로 보존한다. 종목 이름·자유 메모·계좌번호·인증정보 필드는 받지 않는다.

미입력은 필드 부재 그대로다. 빈 문자열·null·음수·알 수 없는 필드는 거부하며 0이나 추정값으로 채우지 않는다. 원가를 필수로 할지와 부분 입력의 상담 정책은 **결정 필요**다. 이 모듈은 상담이나 손익을 계산하지 않는다.

파일은 UTF-8 JSON만 지원한다. 최대 300,000바이트로 제한하며 정규 파일·소유자·권한·하드링크를 확인하고 최종 symlink와 FIFO를 거부한다. 저장은 기존 프로필과 같은 POSIX 정책(디렉터리 0700, 파일 0600)을 따른다. Windows는 ACL 검증을 구현하기 전까지 파일 가져오기·저장·읽기·삭제를 거부한다. 메모리 입력과 합성 KIS 어댑터 시험은 별개다.

## 저장과 삭제 (#43 연결)

`service.save(snapshot, projectRoot, {confirmed: true})`는 `~/.goose/context/holdings-snapshot.json`에만 저장한다. 기존 파일을 바꾸려면 `replace: true`도 필요하다. 프로젝트 내부 경로와 symlink 디렉터리를 거부한다. 임시 파일로 쓴 뒤 원자적으로 게시하고 임시 파일을 정리한다. 자동 백업·이력·보고서 파생 파일은 만들지 않는다. 사용자 PC의 백업·동기화 설정은 이 모듈의 관리 범위 밖이다.

`moai-atp setup --delete-holdings` 또는 `moai-atp /goose setup --delete-holdings`에서 `DELETE`로 확인하면 이 snapshot만 삭제한다. 구독이 끝나도 삭제할 수 있다. 원본 가져오기 파일은 사용자가 선택한 파일이므로 자동 삭제하지 않는다. 파일이 손상됐어도 안전한 정규 파일이면 내용 파싱 없이 삭제한다. 프로필·온보딩·키 삭제는 기존 #43 명령을 그대로 사용한다. 보존기간은 사용자가 지울 때까지다.

## KIS 어댑터

`account-balance.ts`는 기본 체크아웃 `oss/`의 고아 소스를 검토해 재사용한 독립 어댑터다. 근거는 [KIS 공식 inquire_balance 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_balance/inquire_balance.py)다. 허용 경로는 `GET /uapi/domestic-stock/v1/trading/inquire-balance` 하나이며 실전 `TTTC8434R`, 모의 `VTTC8434R`만 선택한다. 계좌 식별자와 인증정보는 로컬 콜백으로만 주입한다. URL·헤더·원문 응답을 결과나 예외로 내보내지 않는다. 허용된 응답 필드만 투영하고 계좌번호·현재 키·토큰 반사를 거부한다.

주문·이체·거래 원장 경로와 자동 재시도·연속조회는 없다. 첫 응답에 다음 페이지 표시가 있으면 `partial_more_pages`다. 수량·평가값은 원문 십진 문자열이며, 통화·단위·원천 평가 시각을 확인했다고 주장하지 않는다. KIS 결과는 수동 입력으로 자동 변환하지 않고 별도 계약으로 저장한다. 실전/합성 출처 표시는 보존한다. 합성 결과를 실제로 승격하지 않는다.

## 확인 범위와 남은 결정

시험은 합성 응답과 임시 홈만 쓴다. 공급자 실호출, 실제 사용자 저장소·키 접근은 수행하지 않는다. 실제 계좌 연결에는 별도 승인이 필요하다. 호스트 연결과 실제 계좌 화면 동작은 미검증이다. 원가 포함 정책, 부분 입력을 이용한 상담 범위, 조회 직후 자동 저장 여부는 결정 필요이며 기본값으로 확정하지 않았다. 저장은 호출자가 별도 확인한 경우에만 수행한다.
