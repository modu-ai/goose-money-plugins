# R06·R08·R11 시장·거시·산업 근거 — 공급자·데이터 계약 선택지

Refs #21 · 기준 커밋 `8711890ce758ebc8b116dc2f6c29ef80851597fe` (main)

이 문서는 설계 선택지와 결정 항목을 정리합니다. 공급자를 확정하지 않으며, 요금·사용량 한도·보존기간·권리 조건은 "결정 필요"로 둡니다. 아래 공급자 후보의 약관·요금·재배포 조건은 이 문서 작성 때 확인하지 않았습니다.

## 1. 지금 있는 것 (측정)

### 1.1 기준 커밋에 등록된 공급자 도구

`git show 8711890:plugins/moai-atp/CAPABILITIES.json`에서 `get_*` 도구 이름 32개를 찾았습니다. 세 보고서와 관련된 것만 추립니다.

| 영역 | 등록된 도구 | 비고 |
|---|---|---|
| 국내·해외 지수 | `get_domestic_index_history`, `get_domestic_index_period_history`, `get_global_index_history`, `get_global_index_period_history`, `get_us_market_snapshot` | 등록돼 있다는 것과 정규화·권리·단위 정리가 끝났다는 것은 다릅니다 |
| 시장 뉴스·수급 | `get_market_headlines`, `get_market_flows`, `get_market_industry_investor_aggregates` | 업종별 투자자 집계가 유일한 "업종" 단위 도구 |
| 종목·공시·재무 | `get_market_snapshot`, `get_price_history`, `get_instrument_profile`, `get_fundamentals`, `get_public_filings` | |
| 추정치 | `get_kis_house_estimates` | 단일 증권사 추정치 후보. 시장 컨센서스가 아님 |
| ETF | `get_domestic_etf_snapshot` | |
| **거시(금리·환율·물가·원자재)** | **없음** | CAPABILITIES.json에서 `ecos`·`bok`·`interest`·`exchange_rate`·`fx`·`cpi`·`inflation`·`macro`·`commodity`·`sector` 문자열 0건 |

### 1.2 보고서 계약이 요구하는 것

격리 후보(이슈 #11의 보존 대상, 아직 main에 없음)의 `server/contracts/report-workflows.v1.json`에 적힌 값입니다.

| 보고서 | 계약에 연결된 공급자 도구 | 입력 요구 | 계약이 밝힌 한계 |
|---|---|---|---|
| R06 국내·글로벌 마켓 브리핑 | `get_market_snapshot`, `get_price_history`, `get_market_flows`, `get_public_filings`, `get_market_headlines` | 시장·세션·현지 시간대, 확정 대상 목록, 관측 cutoff, 사건 기간 | 한 종목으로 시장 폭·주도업종·전체 지수 등락을 만들지 않음 |
| R08 거시·자산배분 브리핑 | `get_market_headlines`, `get_public_filings` | 명시 국가·지표·발표시각·관측기간·빈티지, 실제/예상/이전/수정치의 독립 출처 | 거시 통계·금리·환율·원자재의 정규화 피드 없음. 임의 자산배분 비중을 제안하지 않음 |
| R11 산업·섹터 전망 | `get_instrument_profile`, `get_fundamentals`, `get_public_filings`, `get_market_headlines`, `get_domestic_etf_snapshot` | 업종 범위·비교기업/ETF, 수요·공급·재고 지표의 원출처·기간, cutoff | 업종 통계·밸류체인·컨센서스 피드 없음 |

관찰: R06 계약은 **이미 등록된 지수 도구를 연결하지 않습니다**(1.1의 지수 도구 5개가 R06 `provider_tools`에 없음). 그래서 R06의 빈칸은 "공급자 부재"가 아니라 "계약 연결 누락" 쪽에 가깝습니다. 지수 경로 일부가 막혔다는 과거 기록이 있으니, 연결하기 전에 실제 동작부터 확인해야 합니다.

### 1.3 지금 샘플이 채운 방식

두 회사 샘플(2026-11-09 생성본)의 R06·R08·R11은 회사마다 각 1개씩 모두 한국은행 등 공식 공개 문서를 손으로 옮긴 과거 수치입니다(샘플 manifest의 해당 6개 항목 `data_kind=official_public_document_actual_facts`, `MCP_actual_data_verified=false`). MCP 경로로 들어온 값이 아니고, 갱신 시점도 없습니다.

## 2. 빈칸별 선택지

### 2.1 R06 시장 — 지수·시장 폭

| 안 | 내용 | 장점 | 비용·위험 |
|---|---|---|---|
| R06-A | 이미 등록된 지수 도구 5개를 R06 계약에 연결 | 새 공급자가 필요 없음 | 과거 기록상 국내 지수 경로 일부가 막힘. 단위·시간대·권리 확인 필요 |
| R06-B | 시장 폭(상승·하락 종목 수, 업종 등락)은 업종별 투자자 집계 + 거래소 공개 통계로 따로 계약 | 한 종목으로 시장 폭을 만드는 오류를 막음 | 거래소 자료의 재배포 조건 미확인 |
| R06-C | 당분간 부분 브리핑으로 유지하고, 빈칸을 명시 | 추가 작업 없음 | 사용자 가치가 낮음 |

### 2.2 R08 거시 — 금리·환율·물가·원자재 (공급자 없음)

| 안 | 공급자 후보 | 담을 수 있는 것 | 확인할 것 |
|---|---|---|---|
| R08-A | 한국은행 경제통계 Open API(ECOS) | 기준금리·시장금리·환율·물가 등 국내 거시 시계열 | 키 발급·호출 한도·재배포·캐시 허용 범위, 발표 빈티지(수정치) 표현 |
| R08-B | 통계청 KOSIS Open API | 물가·산업 통계 | 위와 같음 |
| R08-C | 해외 거시 공개 API(예: 미국 연준 계열 통계) | 미국 금리·물가 | 위와 같음 + 해외 자료의 표시·출처 의무 |
| R08-D | 원자재: 등록된 해외 선물 도구(`get_overseas_futures_*`)를 원자재 근사로 사용 | 새 공급자 없이 일부 가격 | 선물 가격은 현물 원자재 지표가 아님. 만기·통화 표기 필요 |
| R08-E | 공급자를 붙이지 않고 R08을 "공식 문서 인용 + 사용자 입력" 보고서로 축소 | 권리 문제가 적음 | 자동 갱신 없음 |

어느 안이든 공통으로 필요한 데이터 계약 필드(제안):
`indicator_id`, `country`, `unit`, `frequency`, `observation_period`, `release_time`, `vintage`(최초·수정 구분), `value_kind`(actual/forecast/previous/revised), `source_id`, `retrieved_at`, `rights_status`.

### 2.3 R11 산업 — 업종 정의·비교군·수요/공급/재고·컨센서스

| 안 | 내용 | 확인할 것 |
|---|---|---|
| R11-A | 업종 정의는 공식 산업 분류(예: 한국표준산업분류) 또는 거래소 업종 코드 중 하나로 고정 | 어느 분류를 기준으로 할지, 종목 매핑 출처 |
| R11-B | 비교군은 사용자가 고르거나, 같은 업종 코드의 종목을 자동 후보로 제시하되 사용자 확정 | 자동 후보의 기준(시가총액·매출 비중) |
| R11-C | 수요·공급·재고 지표는 R08-B(통계청) 산업 통계에서 업종별로 정의 | 업종마다 지표 대응표 필요 |
| R11-D | 컨센서스는 공급자 없음. `get_kis_house_estimates`는 단일 기관 추정치로만 표시 | "컨센서스"라는 이름을 쓰지 않을지 |
| R11-E | 공급자를 붙이지 않고 공시·재무 기반 비교로 축소 | 업종 전망이 아니라 비교 분석이 됨 |
