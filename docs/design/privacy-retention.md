# 개인정보 동의·보존·삭제 정책 (설계 초안)

Refs #9.

- 상태: **초안(제안)**. 보존 기간 숫자는 정하지 않았습니다.
- 1차 출처: 기능 정의서 스냅샷 2장(42행), F02(108–125·129–131행), F14·F15(310–339행), F18(355행대), F19(370–383행), 7장(606행), 9장(640행). 코드 기준: HEAD `8711890`.
- 작성: 2026-11-10 설계 감사. 관련 문서: `docs/design/identity-auth-contract.md`(#6), `docs/design/product-tiers.md`(#5).

## 1. 원칙 (정의서 고정값)

1. 비공개·최소 전송·local-first가 기본 (42행).
2. 계좌 원문·보유 수량/원가·잔고·개인 손익·토큰/비밀은 웹 검색·프로젝트 지침·공개 로그·공유본에 넣지 않음 (42행).
3. **로그인, 서비스 가입, 자료 전송, 외부 게시, 반복 실행은 서로 다른 동의**이며 하나를 다른 효과에 재사용하지 않음 (42행).
4. 보고서 입력 JSON도 개인정보를 담을 수 있으므로 생성 원본과 공유용 redacted 파일을 분리 (606행).
5. 보존 기간·정정/철회·신고 처리는 남은 결정 (640행).

## 2. 동의 단위 (제안)

| 동의 | 효과 | 철회 시 | 근거 |
|---|---|---|---|
| C1 로그인 | Identity 확인만 | 로그아웃 = 로컬 토큰 삭제 | 42행, #6 |
| C2 서비스 가입 | Membership 기록 생성 | 탈퇴 → 서버 기록 삭제 단계(§4) | F04 |
| C3 공급자 키 저장 | 로컬 키스토어 저장 | 키 삭제 명령(현재 **부재**) | F02 121행 |
| C4 투자자 성향 저장 | 로컬 프로필 저장 | `setup delete` (있음) | HEAD `user-context.ts:145` |
| C5 보유 자료 사용(유료) | 보유 snapshot 로컬 저장·분석 | snapshot 삭제 | F14 |
| C6 서버 전송 | 특정 자료를 모두의 AI 서버로 보냄 | 서버 사본 삭제 | 42행 "자료 전송" |
| C7 게시 | 공유판 공개 | 철회(정정·철회 전파) | F19 |
| C8 반복 실행 | 예약 작업 | 예약 해제 | 42행 |

어느 동의도 다른 동의를 대신하지 않습니다. 예: C7(게시)을 했다고 C6(원본 서버 전송)이 생기지 않음.

## 5. 전송(egress) 통제 (제안)

- 공급자 키·토큰: 공급자 공식 endpoint allowlist만 (HEAD: KIS `KIS_BASE_URL.production` 고정, `default-server-ac001.test.ts` 주석 "every request stays on the provider allowlist").
- 보유 자료(6): 기본 egress 0 (정의서 618행 "보유 자료 egress 0 기본"). 외부 검색에는 종목 식별자만.
- 모두의 AI 서버: 인증·가입·게시에 필요한 것만. 분석·원문·보고서 원본 전송은 C6 없이 0.
- 게시(10): 공유판만, 개인 수치 0 (정의서 380행).

## 6. 수용 시험 목록

1. `setup delete` 후 `profile.json` 부재, 다른 파일 불변 (현행 동작 확인용).
2. 키 삭제 명령 추가 후: 키 파일 삭제, 메모리 토큰도 무효화.
3. 로그아웃 직후 이전 보고서 자원 URI → 차단.
4. 유료 보유 분석 실행 중 네트워크 기록: 보유 수량·원가·잔고가 담긴 외부 요청 0.
5. 공유판 생성 시 개인 수치 0, 원본 JSON 미첨부.
6. 게시 철회 후 공개 URL·검색 결과·첨부 접근 차단.
7. 동의 C7만 한 사용자의 원본이 서버에 0건.
8. 오류·로그·stdout에 키·토큰·계좌 원문 0.
