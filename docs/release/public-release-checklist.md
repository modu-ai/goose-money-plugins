## 1. 측정 결과

### 1.1 Git 이력 속 PNG 2개에 남은 AI 출처 메타데이터(C2PA)

| blob | 크기(byte) | 당시 경로 | `caBX` 청크 | 확인한 C2PA 표지 |
|---|---|---|---|---|
| `171773d5` | 1,116,623 | `plugins/moai-atp/assets/modu-stock-plugin-icon-square.png` | 있음 | `c2pa.claim.v`, `c2pa.actions.v`, `c2pa.assertions`, `c2pa.hash.data`, `claim_generator_info` |
| `bc9d0bf3` | 612,662 | `plugins/moai-atp/server/assets/report-runtime/stock-sample-logo.png` | 있음 | 위와 같은 종류 |

측정 명령: `git cat-file -p <blob> | grep -a -c caBX`(각 1), `grep -a -o 'c2pa…'`로 표지 이름만 셌습니다. 서명 내용·생성 도구 이름의 값은 이 문서에 옮기지 않았습니다.

- 두 blob은 `232ffa7`(경로 이동 커밋)에 들어왔고, `1ce9c04`("PNG 두 개에서 caBX(C2PA) 청크를 제거하고 sha256 핀을 갱신")에서 대체됐습니다.
- **현재 HEAD의 두 PNG**는 청크가 `IHDR`, `IDAT`, `IEND`뿐입니다(Python으로 PNG 청크 목록을 읽어 확인). 즉 지금 배포되는 파일에는 C2PA가 없고, **과거 이력에만** 남아 있습니다.
- 집 경로·위치정보: 리더의 push 사전 점검 기록에서는 0건입니다. 이 문서 작성 때 다시 재지 않았습니다.

### 1.2 후보의 새 이미지 asset `artboard-wordmark.webp`

이 파일은 아직 main에 없습니다. 격리 후보(#11 보존 대상)에만 있습니다.

| 항목 | 측정 |
|---|---|
| 형식 | RIFF/WEBP, 136,832 byte |
| 청크 | `VP8X`, `ALPH`, `VP8 ` — `EXIF`·`XMP `·C2PA 청크 없음 |
| sha256 앞 16자리 | `ee87fa6caf33113f` |
| 저장소 비밀 검사 | `check_secrets.py --staged`에서 `unexpected_binary` 1건(#11 기록). 비밀값이 아니라 허용 목록에 없는 바이너리라는 뜻 |
| 출처 기록 | 디자인 도구에서 내보낸 시안 묶음의 `assets/`("디자인에 업로드된 파일")에서 왔다는 기록만 있음. **누가 만들었는지, 어떤 라이선스인지는 기록이 없습니다.** |
| `THIRD_PARTY_NOTICES.md` | 이 파일에 대한 항목 없음 |

메타데이터가 없다는 것은 "AI 생성이 아니다"나 "권리가 깨끗하다"는 증거가 아닙니다. 출처를 알 수 없다는 뜻일 뿐입니다.
