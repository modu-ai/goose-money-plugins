# 논문 기반 전략 설계

전략 엔진은 미구현입니다. 근거를 조사하고 재현 가능한 명세를 작성합니다.

요청 → 시장/상품/기간/목적 확인 → 논문 원문과 원저자 판본 확인 → 규칙 추출 → 데이터·권리·현지 적용 차이 검수 → 전략 명세 → R14 검증 요청 순서입니다. 논문 조사와 시장제도 조사는 host가 허용할 때만 독립 병렬화하고 하나의 writer가 통합합니다.

입력은 원문 URL/버전, universe, signal, entry/exit timing, sizing, cash/leverage constraint, invalidation rules입니다. 빠진 항목은 미정으로 남기고 사용자에게 필요한 결정만 묻습니다. 논문 저자의 표본/빈도/비용 가정을 한국·미국에 그대로 옮기지 않습니다. 핵심 주장별 원문 위치·표본기간·표본 밖 결과·반대 근거·재현 가능성을 기록합니다.

MCP는 권리와 자료 지원이 실제 확인된 읽기 전용 도구만 선택합니다. 현 패키지에는 논문검색이나 전략실행 도구가 없고 데이터 도구는 기본 차단입니다. 공급자 원문과 연구 가설을 섞지 않습니다.

출력은 버전이 고정된 전략 명세, 근거 장부, 미확정 규칙, 필요한 데이터, 비용/체결 가정, 검증 계획이며 `../goose-backtest/SKILL.md`로 넘깁니다. 공통 계약은 `../goose/references/workflow-contract.md`입니다.

수용: 이름이 같은 변형→저자/판본 분리, 규칙 누락→기대수익/계수 생성 0, 한국/미국→세금·세션 차이 미확인 표시, 논문만 조사→백테스트 완료 주장 0, 주문→실행 0. 원문 열람과 합성 명세 검수는 실수익 검증이 아닙니다.
