# 기업·상품 비교

`/goose report R02` 또는 `/goose r02`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R02.md)을 읽어 같은 절차를 수행합니다.

목적: 현재 비교 조립이 지원하는 국내 주식 2~4개 대상의 동일 기준 비교와 선택을 바꿀 조건을 설명합니다.

입력: 확인된 국내 주식 2~4개 대상과 종목 코드·법인 코드 대응, 비교 목적, 같은 기간·기준시각·통화·단위·연결기준, 제외 기준.

MCP: `get_market_snapshot`, `get_fundamentals`, `get_public_filings`. 별도 식별 조회 결과나 receipt는 비교 조립에 전달하지 않습니다. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 국내 주식의 같은 재무 범위·기간 지표만 비교하고 기준이 다른 값은 별도 열에 둡니다. 종목 코드와 법인 코드의 대응을 확인하며, 시세·재무·공시의 출처를 각 대상에 연결합니다. 상대 선호는 관측값과 별도의 조건부 해석입니다.

제약: 현재 다중 대상 비교는 국내 주식의 시세·재무·공시 입력만 받습니다. 매매 추천·전체 종목 최적 선택으로 표현하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
