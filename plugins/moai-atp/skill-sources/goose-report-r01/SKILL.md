# 종목 심층 분석

`/goose report R01` 또는 `/goose r01`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R01.md)을 읽어 같은 절차를 수행합니다.

목적: 사업·재무·가격의 근거를 분리해 한 종목의 투자논지와 반증 조건을 설명합니다.

입력: 확인된 종목 식별자, 분석 목적, 재무 연도·보고서·연결/별도, 가격 기간, cutoff.

MCP: `get_instrument_profile`, `get_market_snapshot`, `get_price_history`, `get_fundamentals`, `get_public_filings`, `get_market_headlines`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 재무 항목의 계정·기간·연결기준을 맞춘 뒤 매출·영업이익·현금흐름을 대조합니다. 원문 금액의 통화·배율이 확인될 때만 수치와 비율을 계산합니다. IS/CIS의 같은 계정·기간·값은 표시 중복인지 확인하고 합산하지 않습니다.

제약: 단일 시세는 추세 차트가 아닙니다. 비교기업·컨센서스·미래 목표가격 근거가 없으면 해당 부분을 결측으로 남깁니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
