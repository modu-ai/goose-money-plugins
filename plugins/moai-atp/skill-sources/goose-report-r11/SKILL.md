# 산업·섹터 전망

`/goose report R11` 또는 `/goose r11`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R11.md)을 읽어 같은 절차를 수행합니다.

목적: 확인된 업종·기업 자료로 산업 전망의 근거와 반증 조건을 설명합니다.

입력: 확정한 업종 범위·비교기업/ETF, 수요·공급·재고 지표의 원출처·기간, cutoff.

MCP: `get_instrument_profile`, `get_fundamentals`, `get_public_filings`, `get_market_headlines`, `get_domestic_etf_snapshot`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 업종 정의와 비교군 선정 이유를 먼저 적습니다. 기업 수치를 업종 전체로 외삽하지 않습니다. 공급·재고·가격 및 이익추정 변화는 서로 다른 지표로 출처를 붙이고 전망은 가정·반증 조건을 함께 제시합니다.

제약: 업종 전체 통계·밸류체인·증권사 컨센서스 피드가 완성된 것은 아닙니다. 상품 NAV만으로 업종 노출이나 구성종목을 확정하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
