# 투자논지·관심종목 점검

`/goose report R09` 또는 `/goose r09`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R09.md)을 읽어 같은 절차를 수행합니다.

목적: 사용자가 준 이전 투자논지와 새 근거를 대조해 유지·반증·보류 사유를 기록합니다.

입력: 이전 논지 원문/판본·확인일, 사용자 관심대상 목록, 주장별 확인 지표·기각 조건·다음 점검일.

MCP: `get_market_snapshot`, `get_price_history`, `get_fundamentals`, `get_public_filings`, `get_market_headlines`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 이전 논지를 변경 불가능한 비교 기준으로 따로 보존합니다. 주장마다 지지·반대 근거, 동일 원천 재인용 여부와 불확실성을 적습니다. 증거가 부족하면 판단불가로 두고 다음 점검 조건만 제시합니다.

제약: 관심목록 저장·논지 버전 DB·예약 점검 MCP는 없습니다. 이전 논지가 없으면 변화·유지 판정을 만들지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
