# 마감 전 후보·거래조건 점검

`/goose report R10` 또는 `/goose r10`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R10.md)을 읽어 같은 절차를 수행합니다.

목적: 사용자가 지정한 후보의 마감 전 자료 신선도와 관측 조건을 점검합니다.

입력: 사용자 후보 목록, 시장·거래일·세션·cutoff, 명시한 조건/문턱값, 가격·거래량·호가 관측시각.

MCP: `get_market_snapshot`, `get_intraday_price_history`, `get_market_orderbook`, `get_public_filings`, `get_market_headlines`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 확정 후보만 검사하고 각 조건을 충족/기각/자료부족으로 나눕니다. 지연·세션·거래정지 미확인이면 체결 가능하다고 하지 않습니다. 호가 스프레드는 동일 관측시각·확정 단위의 양쪽 가격이 있을 때만 계산합니다.

제약: 전 종목 스캐너·HTS 조건 저장·주문 도구는 없습니다. 장 종료 후 자료를 마감 직전 실시간 검사로 표현하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
