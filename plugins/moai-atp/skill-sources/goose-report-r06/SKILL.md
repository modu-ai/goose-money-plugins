# 국내·글로벌 마켓 브리핑

`/goose report R06` 또는 `/goose r06`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R06.md)을 읽어 같은 절차를 수행합니다.

목적: 시장별 관측 사실과 주요 사건을 기준시각이 드러나는 브리핑으로 정리합니다.

입력: 시장·세션·현지 시간대, 확정 대상 목록, 관측 cutoff, 사건 기간.

MCP: `get_market_snapshot`, `get_price_history`, `get_market_flows`, `get_public_filings`, `get_market_headlines`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 시장별 거래일·세션과 한국시간 수집시각을 따로 표시합니다. 관측한 대상만 가격판에 넣고 사건은 원문 발행시각과 정정 여부를 대조합니다. 사건과 가격의 동시 발생을 인과관계로 확정하지 않습니다.

제약: 한 종목으로 시장 폭·주도업종·전체 지수 등락을 만들지 않습니다. 지수/거시 자료 연결이 부족하면 부분 브리핑으로 제공합니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
