# 선물 계약·시황·만기 위험

`/goose report R13` 또는 `/goose r13`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R13.md)을 읽어 같은 절차를 수행합니다.

목적: 초기 출시에서 보류된 선물 보고서의 개발 계약과 미지원 범위를 확인합니다.

입력: 향후 승인된 계약 식별·시장·만기·승수·단위·세션·cutoff가 필요하나 현재 명령은 실행하지 않음.

MCP: 공급자 호출 없음. 로컬 생성: 실행 보류.

계산·해석: 서브커맨드는 report_scope_deferred와 실행 단계 0개를 반환합니다. 기존 개발 템플릿·선물 MCP 등록은 보존하지만 현재 제품의 보고서 실행이나 공개 지원으로 승격하지 않습니다.

제약: 초기 출시 보류. 선물 시세·이력 도구가 등록돼 있어도 이 워크플로에서 호출하지 않습니다. 증거금·손익·롤오버·포지션·주문·자동매매를 제공하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
