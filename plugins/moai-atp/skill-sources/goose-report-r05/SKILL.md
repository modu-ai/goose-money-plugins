# 수동 입력 비용 영향 상담

`/goose report R05` 또는 `/goose r05`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R05.md)을 읽어 같은 절차를 수행합니다.

목적: 명시된 비용 가정의 정적 연간 금액과 동일 기준 차이를 비공개로 설명합니다.

입력: manual_consultation의 cost_assumptions, snapshot·기준시각·통화, 명시 적용금액·연간률·고정액.

MCP: 공급자 호출 없음. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 연간 비용 = 명시 적용금액 × 명시 연간률 / 100 + 명시 연간 고정액입니다. 같은 통화·적용기준일 때만 가정별 차이를 비교합니다. 미입력 비용을 0으로 바꾸지 않습니다. 실제 부과 비용과 가정 계산을 분리합니다.

제약: 세금·환전·거래수수료·수익률은 임의 추정하지 않습니다. 상담은 거래·세금 신고나 비용 최적화 보장을 수행하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
