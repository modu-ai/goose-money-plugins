# 거시·자산배분 브리핑

`/goose report R08` 또는 `/goose r08`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R08.md)을 읽어 같은 절차를 수행합니다.

목적: 확인된 거시 발표와 자산 노출의 조건부 전달 경로를 설명합니다.

입력: 명시 국가·지표·발표시각·관측기간·빈티지, 실제/예상/이전/수정치의 독립 출처, 사용자 노출 가정.

MCP: `get_market_headlines`, `get_public_filings`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 현재 도구는 사건 메타데이터의 보조 자료입니다. 거시 통계 발표 원문이 확인되지 않으면 발표/예상/수정치 표를 채우지 않습니다. 확보된 실제 지표에만 전달 경로를 조건부 해석으로 붙이고 반대 시나리오를 적습니다.

제약: 거시 통계·금리·환율·원자재의 완결된 정규화 피드가 없습니다. 자료 부족은 부분 보고서 또는 보류로 표시하며 임의 자산배분 비중을 제안하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
