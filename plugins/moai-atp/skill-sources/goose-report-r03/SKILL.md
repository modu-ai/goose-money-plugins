# 시장 수급·자금 흐름

`/goose report R03` 또는 `/goose r03`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R03.md)을 읽어 같은 절차를 수행합니다.

목적: 가격과 투자자별 수급의 동행·엇갈림 및 관측 한계를 설명합니다.

입력: 대상 시장·종목, 수급 기간, 주체 정의, 원문 단위·배율, cutoff와 세션.

MCP: `get_market_flows`, `get_price_history`, `get_credit_balances`, `get_short_sale_activity`, `get_stock_lending_activity`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 일별/기간 누적과 순매수/보유잔고를 구분합니다. 단위·반환 날짜가 확인된 행만 합산하며 겹친 날짜·중복 행을 제거한 근거를 남깁니다. 거래대금 대비 강도는 같은 기간·단위의 분모가 있을 때만 계산합니다.

제약: 개별 종목 수급으로 시장 전체 자금 유입을 단정하지 않습니다. 업종·ETF 설정환매·선물 포지션은 현재 검증 자료가 없으면 결측입니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
