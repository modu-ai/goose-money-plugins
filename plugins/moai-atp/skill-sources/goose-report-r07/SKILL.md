# 실적·공시 이벤트 리뷰

`/goose report R07` 또는 `/goose r07`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R07.md)을 읽어 같은 절차를 수행합니다.

목적: 특정 실적·공시 사건의 확인 사실, 변화와 후속 확인 조건을 설명합니다.

입력: 확인된 법인, 사건·공시 접수번호/기간, 원문 판본·발행시각, 재무 연도·보고서·연결기준.

MCP: `get_public_filings`, `get_fundamentals`, `get_market_headlines`, `get_market_snapshot`. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 목록/제목과 본문을 구분합니다. 공시 목록을 읽은 것만으로 계약 내용·규모·일회성 원인을 요약하지 않습니다. 확인된 원문과 같은 기간 재무만 연결하고 정정판은 원판과 분리합니다. 예상 대비 차이는 실제 예상치의 출처가 있을 때만 계산합니다.

제약: 공시 제목은 본문 사실을 입증하지 않습니다. 컨센서스·가이던스·사건 전후 가격이 없으면 서프라이즈나 시장 반응을 추정하지 않습니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
