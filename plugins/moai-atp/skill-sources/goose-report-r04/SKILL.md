# 수동 입력 보유·리스크 상담

`/goose report R04` 또는 `/goose r04`에서 사용합니다. 공개 검색 진입점은 Goose 하나이며 이 스킬은 내부 작성 원본입니다. 패키지에서는 [보고서별 실행 지침](../../skills/goose/references/reports/R04.md)을 읽어 같은 절차를 수행합니다.

목적: 사용자가 직접 준 현재 보유 snapshot의 비중·집중도와 목표 차이를 비공개로 설명합니다.

입력: manual_consultation의 holdings_snapshot, 기준시각·통화·현재 평가액·현금, 명시 목표·기간·현금 필요·제약.

MCP: 공급자 호출 없음. 로컬 생성: `build_report_input`, `render_report_html`.

계산·해석: 수동 입력 계약의 엄격한 schema를 적용합니다. 같은 통화의 현재 평가액과 현금으로 총액·비중을 계산하고 명시한 목표 비중과의 차이만 구합니다. 식별자별 집중도를 보여주되 업종·발행사 분류를 추측하지 않습니다.

제약: 계좌·매입가·거래/입출금 원장·TWR·과거 수익률은 입력이나 계산 대상이 아닙니다. 실제 사용자 입력이 없으면 synthetic fixture라고 표시합니다.

중요 수치와 주장을 원출처·기간·단위·기준시각/수집시각에 연결합니다. 관측/계산/추론/결측을 구별하고 개인 투자자가 이해하기 쉬운 문장으로 씁니다. 기존 receipt·권리·키 전송·비공개·주문 차단을 유지합니다. `plan_only`를 실행 완료로 설명하지 않습니다. 실제 화면과 코드 검사·fixture 검증은 구분합니다.
