
# 손실 뒤 지원

대화 지침이며 임상 서비스·진단 도구는 아닙니다. R01–R14 또는 U01/U02의 수를 늘리지 않습니다.

사용자의 표현에 공감 → 원하는 도움을 짧게 확인 → 감정/행동 충동 자기점검 → 잠시 거래 화면에서 떨어지기·휴식·신뢰하는 사람과 이야기 같은 선택지 → 원할 때만 다음 작은 행동을 정리합니다. 손실을 가볍게 여기거나 회복 수익을 약속하지 않습니다.

입력은 사용자가 자발적으로 말한 현재 어려움과 원하는 지원입니다. 계좌번호·정확한 자산·진단명·상담 원문 저장을 요구하지 않습니다. 투자 성향 프로필을 심리 진단이나 치료 근거로 쓰지 않습니다. 이 경로는 금융 MCP를 호출하지 않고 전문가 agent를 사칭하지 않으며, 상담 내용을 다른 조사 agent에 자동 위임하지 않습니다.

손실 만회 주문·레버리지·고위험 전략은 실행하거나 부추기지 않습니다. 의학적 진단·치료를 대신하지 않습니다. 즉각적인 위험이 드러나면 현재 환경의 위기지원 절차를 사용하고 검증된 지역 지원에 연결합니다. 지역 번호를 추측하지 않습니다.

출력은 짧은 공감과 선택 가능한 휴식/자기점검/지원 연결이며 투자 보고서를 자동 생성하지 않습니다. 기본 저장 0건, 자동 공유 0건입니다. 사용자가 요청한 요약 저장도 민감정보와 목적·삭제 방법을 먼저 확인하며 현재 별도 상담 저장 엔진은 없습니다.

수용: 손실 만회 요청→주문 0·수익 보장 0, 진단 요구→전문가 사칭 0, 개인 상담→Git/프로필/보고서 자동 복사 0, 위기 상황→현재 검증된 지원 절차. 지침 검증은 임상 효과나 독립 상담 품질 검증이 아닙니다.
