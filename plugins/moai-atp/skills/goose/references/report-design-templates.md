# 보고서 디자인 선택과 제공

플러그인에는 기존 디자인 `existing`과 아트보드 참조 디자인 `artboard-v2`가 포함됩니다. 설치 파일의 `server/assets/report-runtime/report-design-templates.v1.json`에서 템플릿과 UI 유형 대응, CSS·로고 경로를 확인할 수 있습니다. R1–R8은 UI 분류이며 ATP 보고서 ID R01–R08과 일대일로 같지 않습니다.

보고서 입력을 먼저 `build_report_input`으로 조립한 뒤, 반환된 입력을 `render_report_html`의 `report_input`으로 넘깁니다. 아트보드 디자인을 요청받으면 `template: "artboard-v2"`를 함께 전달합니다. 이 값을 생략하면 기존 디자인을 유지합니다. 반환된 MCP resource link는 같은 실행 세션에서 `resources/read`로 읽을 수 있으며 메모리 보관 기간이 지나면 만료됩니다. 실제 호스트 화면 표시·다운로드는 별도 확인이 필요합니다.

템플릿 선택은 자료 조회나 인증·권리 승인이 아닙니다. KIS 수신 결과는 서버가 발급한 근거 영수증을 통해 조립하고, 원천 기준일과 수집 시각을 구분합니다. API 실패, 인증 만료, 결측, 부분 자료는 그대로 표시하며 임의 수치로 채우지 않습니다. 단일 시세 조회로 기업 심층 보고서의 모든 분석이 완성됐다고 설명하지 않습니다.

활성 보고서 14개는 두 디자인을 공통으로 사용합니다. UI의 R3 실적과 R4 사건은 현행 R07 경로의 의미 대응이며 별도 두 엔진을 추가한 것은 아닙니다. R5 포트폴리오(R04)는 차단 상태이며 R6 근거 검증(U03)은 내부 QA입니다. UI의 R7에 있는 예약·종가 확정 자동화와 게시·등급 정책은 디자인 선택으로 구현되지 않습니다.

원본 로고와 보고서용 CSS를 포함하고, 좁은 화면·인쇄용 ATP 어댑터를 사용합니다. 서체는 로컬 설치 및 시스템 대체 서체를 사용하므로 원본과 동일한 서체 모양을 보장하지 않습니다. 실제 브라우저·모바일·PDF 확인 결과는 따로 보고합니다. 보고서 공개·전송은 이 렌더링 도구가 수행하지 않습니다.
